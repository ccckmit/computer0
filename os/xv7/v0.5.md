# v0.5 — C 虛擬機 (vm.c)

## 摘要

從 Rust 實作的 rvemu4 重寫為單一 C 檔案 `vm/vm.c`（1115 行），可在 host 上模擬 RISC-V 64 位元虛擬機器，載入 xv7 kernel 並搭配 fs.img 磁碟映像開機。

## 與 v0.4 (rvemu4 Rust) 的差異

| 項目 | v0.4 (rvemu4) | v0.5 (vm.c) |
|------|---------------|-------------|
| 語言 | Rust | C11 |
| 行數 | ~5000+ (多檔案) | 1115 (單檔案) |
| 壓縮指令 (RVC) | 有實作（但有 bug） | **不支援**（kernel 以 `-march=rv64g` 編譯時應避開 C 擴展） |
| 多核心 | 有 | **不支援**（僅單核） |
| 浮點 | 有 | **不支援** |
| 原子操作 (A) | 標準 | 單核簡化版 |
| 網路 (virtio-net) | 無 | **未實作**（回報 device-id=0） |
| 中斷 | 部分 | PLIC + Sstc 計時器中斷 |

## 實作狀態

### 已完成
- RV64I 整數指令集（ADD, SUB, ADDI, LW, LD, SW, SD, BEQ, JAL, LUI, AUIPC, ...）
- RV64M 乘除法擴展（MUL, DIV, REM, ...）
- RV64A 原子擴展（單核簡化版 LR/SC/AMO）
- OP-IMM-32 / OP-32 32 位元運算指令
- CSR 讀寫（mstatus, satp, stvec, sepc, scause, sie, sip 等）
- 特權等級切換（M → S → U）
- Sv39 分頁（3 層 page table, superpage 支援）
- MMU translate 含 A/D bit 更新
- ECALL / EBREAK / MRET / SRET / SFENCE.VMA / WFI
- 陷阱委派（medeleg / mideleg）
- UART 16550a（終端機輸入輸出）
- PLIC 中斷控制器
- Goldfish RTC（`gettimeofday`）
- VIRTIO-BLK（fs.img 磁碟讀寫）
- ELF loader

### 待實作 / 已知問題
- kernel 以 `-march=rv64g` (`rv64imafdc`) 編譯，產生約 10811 條壓縮指令，但 vm 不支援 RVC → **kernel 須改用 `-march=rv64imafd` 重新編譯**
- stimecmp 計時器中斷需驗證
- WFI 目前為 no-op（應暫停直到中斷）
- 無 GDB stub
- 無網路功能

## 編譯與執行

```bash
cd vm && make
./vm -kernel ../kernel/kernel -drive ../fs.img
```

## 指令集覆蓋率

- RV64I: 完整
- RV64M: 完整
- RV64A: 完整（單核簡化）
- RV64C: ❌ 不支援
- RV64F/D: ❌ 不支援

## 原始碼結構（vm.c 1115 行）

1. **硬體狀態**（~120 行）: CPU 暫存器、CSR、UART、PLIC、VIRTIO-BLK 結構
2. **記憶體存取**（~80 行）: RAM 讀寫 (8/16/32/64 bit)、MMIO 分派
3. **MMU**（~90 行）: Sv39 位址轉換
4. **CSR 與陷阱**（~100 行）: CSR 讀寫、陷阱處理、中斷偵測
5. **CPU 執行**（~250 行）: 指令解碼與執行（`cpu_step`）
6. **ELF loader**（~35 行）
7. **主程式**（~40 行）
